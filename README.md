# Goblin Trader Free

무료 주식시장 시뮬레이션 게임 프로젝트

## Concept

증권사 트레이더가 되어 가상의 시장을 운영하는 게임.

## Main Features

- 가상 주식 거래
- 실시간 시장 진행
- 5분 단위 가격 변화
- 랜덤 뉴스 이벤트
- 매수 / 매도 시스템
- 캔들 차트
- 시장 심리 시스템
